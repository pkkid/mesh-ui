## 5. Decisions made

1. macOS ships unsigned with an ad-hoc signature; hardened runtime off
   (it needs a loosened entitlement under ad-hoc); no `release`
   environment while nothing is signed (maintainer, #219).
2. Unsigned macOS never downloads updates: it checks and links to the
   GitHub release (Squirrel.Mac rejects ad-hoc builds) (#217).
3. Nothing installs on quit; only Install restarts the app (#217).
4. Beta channel is `allowPrerelease`; turning it off keeps an installed
   beta until a newer stable (#217).
5. Account writes with no live-tested source answer "not available yet"
   on the real network, with controls still visible (#214).
6. Time zone is read-only on the real network and dimmed in the renderer
   by checking `app.info.backend` (#216). This differs from 5; see open
   items.
7. Frustration-Free Setup write removed rather than left unverified (#220).
8. Weekly report row left out until a capture names its setting (#214).
9. "New device joins" counts all device events this week (#214).
10. Shared networks read "Shared with you"; the list has no owner name
    (#215).
11. Install CLI only when `APPDIR` contains the running executable; the
    same rule now decides install kind (#218, #222).
12. Speed test lock is a file per network under `<configDir>/locks` for
    the eero backend; demo keeps it in memory. A three-way stale-lock race
    is accepted (#220).
13. Clearing the network nickname sends an empty `label` (no client does
    this; manual check below) (#216).
14. `.cmd` files are stored LF and checked out CRLF (#212).
15. Release notes come from the newest review; a 0.6.x patch edits the
    draft notes by hand (#213, #223).
16. Docs-only PR #223 was self-reviewed (standing rule); every other PR got
    an outside review (gpt-6.1-sol).

## 6. Numbers, surprises, open items, next

**Numbers.** 15 PRs, 1122 to 1276 tests, `pnpm check` 6.5 s, 148 commands
in the registry. Up to seven workers at once.

**Surprises.**
- No signed-in session on this machine, so none of the planned read-only
  captures ran. Every account write that needed one stayed off on the real
  network.
- electron-updater cannot install on an ad-hoc signed Mac, so the unsigned
  decision also turned macOS updates into manual downloads.
- `APPIMAGE` leaks into child processes of any AppImage (T3 Code is one),
  which fooled install kind detection (#222).
- `isAsyncEncryptionAvailable()` is true even under `basic_text`; only the
  backend-name check keeps that case in memory (#209).
- Fedora needs `libxcrypt-compat` for electron-builder's packager; workers
  unpacked it in scratch rather than installing it.

**Open items** (carried in the roadmap under After M6, "Follow-ups from
M6", as 0.6.x issues):
- Captures for `endpoints.md` section 20, then turn on the live account
  writes that have a source (question 4).
- Time zone write: find a request eero applies.
- One way for the UI to learn which writes the live backend lacks (a
  command or capability flag), replacing the renderer `backend === "eero"`
  check in the Wi-Fi page (decision 6).
- Remove the unused `ComingSoonButton` export (`components/ui/page.tsx:41`)
  and the dev-only `ComingSoon` route fallback.
- `ui:shot` has no `--password-store` passthrough, so the memory-only sign
  out text has a unit test but no screenshot.
- `release-notes.mjs` repeats the newest review for patch releases.
- The carried M5 manual checks (question 3).

**Process lessons** (question 5):
- Worker prompt: re-run the `merge-base --is-ancestor` check after any
  retried merge call, not only before the first one. M6.5 merged one
  commit behind because a retry skipped it (tree identical, lead re-ran
  `pnpm check` on the tip).
- Worker prompt: "never end a run waiting on a review" also applies to a
  resumed run. M6.4-fix ended its resume waiting on Sol and needed a
  second nudge.
- `milestone-plan`: when the first story's captures need a signed-in
  session, add a preflight line that the maintainer signs in on the
  worker machine first; otherwise every capture-dependent write is lost
  for the milestone.
- Lead: when a maintainer decision changes a merged story, send the
  dependent running workers a steer at once (done for M6.5; it worked).

**Next.** Answer the questions, run the dry run and the risk-free checks

There is no M7; later work is 0.6.x fixes from issues.
