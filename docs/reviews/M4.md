## 5. Decisions made

Each can be reversed by number.

1. A write marks its topics stale at once and again 2 s later; the write
   itself is not delayed (#149).
2. Credential reads never reuse a finished shared `GET {net}` but may join
   one still in flight (#149).
3. The audit log lives in `engine.execute`, for the live backend only (not
   UI, demo or fake), newest 1,000 lines (#149).
4. Confirm text always comes from core's `needs_confirm` message, so the
   app, CLI and MCP read the same words (#150, #156, #158).
5. Undo is offered only for reversible writes that changed something; no
   Undo for disruptive Wi-Fi and guest saves, so an old password is never
   held in a toast (#154, #156, #157).
6. "No profile" means eero's default profile; Unassigned pause and resume
   is one `PUT` to that profile (#155, #157).
7. Profile names are unique and trimmed; schedule names are unique only
   when set or changed (#155, #161).
8. Bulk device writes run one device at a time, up to 50, with failures per
   device (#157).
9. Wi-Fi rename is `PUT {net}/settings` form `name` (#156).
10. `eero.find` has no Stop and uses `led_cycle` by serial (#158).
11. Restart estimates live in core (`RESTART_ESTIMATE`, Wi-Fi impact) until
    `settings.impact` exists in M5 (#156, #158).
12. One speed test at a time per network, per process; `rate_limited` with
    the reason otherwise (#162, #164).
13. The internet plan is app-local, with an optional name (#162).
14. Schedule days are sent as `MON`..`SUN`; reads accept both forms (#161).
15. Guest rename keeps the network's current on or off state; the main SSID
    check ignores case (#154).
16. Send to a guest copies an invite text instead of opening `sms:` or
    `mailto:`; the print card is black on white (#154).
17. Overview's Share Wi-Fi opens the Wi-Fi page; Pause a profile is a small
    menu, not the palette (#164).
18. The palette's gates come from a table keyed by command id until gates
    move into core (M5) (#152).

## 6. Numbers, surprises, open items, next

**Numbers.** 16 PRs, 657 to 842 tests, `pnpm check` 4.7 s, 133 files
changed. Six workers at once in wave 2. Every PR got an outside review
(gpt-6.1-sol), which found real bugs in six of them.

**Surprises.**
- A Claude API rate limit stopped three wave-2 workers at once mid-run.
  Two resumed by themselves; the third ended while "waiting on a review"
  with no PR open and had to be told to self-review. M4.8's worker never
  sent a final report (its PR merged and was checked here).
- Tests that read before a write retried a fake 500 with backoff and timed
  out; three workers hit it and converged on answering 400 instead.
- Device type names in the demo fixtures and icons did not match eero's
  (`laptop` vs `laptop_computer`), so the demo type grid showed no current
  type (#160).

**Open items (carried in the roadmap).**
- M5: write gates into core; a shared Share Wi-Fi sheet; "New profile from
  selection"; `failed[].name`; timeline segment click; Unassigned
  schedules; restart copy and the Wi-Fi security estimate from
  `settings.impact`; `led_cycle` id or serial; palette "Running..." under a
  pending confirm and no Undo on a palette `device.pause`; docs and
  fixtures from the manual check answers.
- M6: the speed test lock is per process; the CLI and agents panel reads
  the audit log.

**Process lessons** (proposed edits to the milestone skills):
- Lead: when a worker run fails on a provider rate limit, check its branch
  and PR first; resume on the same thread with a short status (what merged
  since, what to rebase on).
- Worker prompt: "never end your run waiting on a review" needs to say
  "including after a resume", since a resumed worker forgot it.
- `milestone-plan`: shared test files touched by every story
  (`src/core/demo/backend.test.ts`, `src/core/audit.test.ts`) belong in the
  hotspot list with an owner, so the first story fixes them for the rest.
- `milestone-review`: check each Done when line against a named test before
  the review; the CLI and MCP parity test was missing until the review
  added it (#166).
