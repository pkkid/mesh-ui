Changes

What's new in Mesh UI

Every release, newest first. Downloads and checksums are on each GitHub release.

1.0 November 2026

  • Full visual and layout overhaul: every page reviewed and updated by hand for consistent styling, cleaner control placement, and unified modals, sheets, popovers, menus, switches and checkboxes.
  • Rebuilt Signal page: an actionable Wi-Fi health view with median signal, per-eero strips, a mesh map you can zoom and pan, a coverage scan, 4-hour signal history, airwaves and channel use, Wi-Fi generation insights, and a "Worth a look" list of recommendations.
  • Regular, disruptive and destructive actions: clearly separated in the app, the CLI and the MCP server, so disruptive actions (yellow confirm) and destructive ones (red confirm) always ask first.
  • Sign in with Amazon alongside email and phone codes, plus a refreshed sign-in screen that formats phone numbers as you type.
  • Built-in eero API dev tools (F12): a docked panel showing live requests to and from the eero API, with status, command, headers, collapsible JSON bodies, timing, filtering, and tokens removed automatically.
  • VS Code themes and a theme editor: search and install themes from Open VSX, or duplicate, customize and export themes in the floating theme editor.
  • System tray and startup: an optional "Keep running in the tray" so desktop alerts keep arriving, and "Start at login".
  • Navigation and shortcuts: Back and Forward buttons in the sidebar, searchable breadcrumb switchers on eero, device and profile pages, a stronger search palette (pages, sections and eeros), and six rebindable keyboard shortcuts.
  • Smarter monitoring and polish: an opt-in Live throughput switch on Devices, a local Activity history beyond eero's 15-minute window, product icons for every eero and Echo, a sortable Devices table that remembers its sort and window state, MCP setup for Codex and Antigravity, and Linux AppImage update information for Gear Lever.

0.6 November 2026

  • First public release for Linux, Windows and macOS.
  • Application and account page: edit your name, email and phone, turn notifications and alerts on or off, see your networks (shared and offline ones too) and switch between them, pick a theme, and sign out or delete your account.
  • Updates: About shows whether Mesh UI is up to date, downloading or ready to restart, with a chip in the sidebar when an update is ready. Unsigned macOS builds link to the download on GitHub.
  • Command line on your PATH: Install CLI for the AppImage and macOS; the deb and rpm packages add /usr/bin/mesh-ui, and the Windows installer adds it to your PATH. A CLI and agents panel helps set up MCP.
  • Demo mode: try Mesh UI from the sign-in screen without an eero account, and leave demo mode to sign in for real.
  • Wi-Fi: edit the network nickname and print a Wi-Fi card for guests.
  • Activity: a menu on each row to rename or block a device.
  • Installers for every system, and a README that walks through them.
